# FatooraLite application workspace

The full project guide is in the [repository README](../README.md): product workflows, configuration, database setup, checks, screenshots, limitations, versions, and license.

Run application npm commands from this directory. Start with `npm install`, copy `.env.example` to `.env`, configure an isolated development database, apply the documented migrations, and run `npm run dev`. See [START-HERE.md](../START-HERE.md) for current state and database-test isolation requirements. Existing production gates and the required dependency-audit check still apply.
