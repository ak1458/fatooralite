# Incident records

One file per incident, named `YYYY-MM-DD-short-slug.md`, using the template
in `docs/20-incident-response.md` §5. Record every severity-1/2 incident and
any severity-3 incident lasting over 15 minutes.

No example/placeholder incident lives in this folder — an empty folder
means no qualifying incident has happened yet, not that recording was
skipped.
